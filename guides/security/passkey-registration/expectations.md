- The implementation detects support using platform authenticator capabilities prior to displaying passkey UI.
- The client invokes native browser passkey creation when the registration trigger is clicked.
- The client decodes server creation options using parseCreationOptionsFromJSON before invoking the authenticator.
- The client submits the attestation to the verify endpoint as JSON-encoded credential data.
- The client signals signalUnknownCredential using Base64URL credentialId upon server verification failure.
