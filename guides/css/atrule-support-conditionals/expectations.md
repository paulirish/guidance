- Stylesheets conditionally apply CSS rules or declarations based on at-rule support using `@supports at-rule(@<name>)` or a fallback detection pattern (`@supports` property, value, function, or `selector()` query, a tautological `@container style(...)` query, a registered `@property` custom property fallback, or a JavaScript CSSOM check that toggles a root class).
- At-rule support detection either passes a bare `@<name>` identifier to `@supports at-rule(...)` (without descriptors, preludes, or rule bodies) or uses a fallback detection pattern, and does not use `@supports (container-type: style)` or `CSS.registerProperty`.
- At-rule support conditionals gate dependent regular CSS declarations or rules in stylesheets rather than wrapping only the detected at-rule itself or applying visual inline styles directly from JavaScript.
