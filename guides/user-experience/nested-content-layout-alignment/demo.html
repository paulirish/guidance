Global Grid Alignment

This demo uses CSS Subgrid to allow deeply nested elements to align perfectly with a parent page grid, supporting complex layouts like full-bleed sections without manual margin calculations.

Subgrid Not Supported: Your browser does not support grid-template-columns: subgrid. The layout below will fallback to standard grid behavior, which may cause nested items to lose alignment with the global page columns.

Aligned to Content Column

Despite being nested 4 levels deep (Body → Main → Article → Section → Div), I am perfectly aligned to the page-content track of the global grid. This is achieved by setting grid-template-columns: subgrid on every parent container in the hierarchy.

Full-Bleed Layout

I span from page-full-start to page-full-end. Subgrid allows me to break out of my parents' logical boundaries to touch the edges of the viewport while remaining part of the same coordinate system.

Consistent Vertical Rhythm

Because I inherit the parent's grid definition, I don't need to know the specific widths or paddings of the containers above me. I simply reference the named lines of the root grid.
