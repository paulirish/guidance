Manual Layout Control (Negative Example)

Managing visibility through explicit state tracking and hardcoded display values is brittle and complex.

Brittle Pattern: This demo tracks "original-display" values in data attributes and manually reapplies them. If the layout requirements change (e.g., a block becomes flex), every data attribute must be updated.
Block Element: Manually restored via .style.display = 'block'.
