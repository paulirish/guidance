- The stack container uses CSS scroll-snap mandatory.
- The stack container has `overflow-x: auto` or `scroll`.
- Each view has width equal to stack width and is not absolutely positioned.
- The stack uses `overscroll-behavior-x: none`.
- The stack uses `100dvh` for height.
- Each view applies `scroll-snap-align: start`.
- Each view applies `scroll-snap-stop: always`.
- The visible horizontal scrollbar is hidden.
- Parallax transform or animation is applied to nested inner element and NOT directly to the snap target.
- The scroll-driven parallax effect is wrapped in `@supports (animation-timeline: view())`.
- Parallax animation uses `animation-timeline: view(inline)` and animation-range confined to exit phase.
- Drop-shadow is applied to drill-down views but NOT to the root view.
- `scroll-behavior: smooth` on the stack is declared only inside `prefers-reduced-motion: no-preference`.
- Programmatic scrolls are performed and do not use hardcoded smooth behavior.
- Active-view-change detection uses `scrollsnapchange` event on the stack.
- An `IntersectionObserver` fallback is provided for browsers without `scrollsnapchange`.
- Every view except the currently-active one carries the `inert` attribute.
- Focus is moved to the back button of a freshly-pushed drill-down view, or to the active view's content container when focus was in the stack and would otherwise be lost.
- Focus is restored to the link originally clicked when navigating back.
- `document.title` changes to name the active view on every active-view change.
- Calls to focus inside the stack pass `{preventScroll: true}`.
- Drilling down calls `history.pushState` with depth tracking.
- A `popstate` listener on window updates the visible view in response to back navigation.
- Reconciles history via `history.go` when a manual scroll changes active view depth.
- Deep links are handled on initial load and depth-0 is seeded with `replaceState`.
- Synthesizes a root entry when Back is clicked from a deep-linked entry with no in-app history.
- Drill-down triggers are real anchor elements with href attributes.
- Click handler preserves modifier keys and middle click behavior.
- Clicks on external links do not trigger drill-down or call `preventDefault`.
- Drill-down views have an explicit back button (whose accessible name includes the title of the view it returns to), and the root view does not.
- Scroll behavior on popstate is correctly selected based on transition type.
- Views that are swiped or navigated back past are removed from the DOM.
- Pruned views are successfully rebuilt from URL on forward navigation.
