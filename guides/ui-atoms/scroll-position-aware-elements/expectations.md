- Uses CSS container-scroll-state-queries as the primary scroll state detection method
- Falls back and shows or hides the button on scroll when container-scroll-state-queries is not supported
- Uses IntersectionObserver for fallback scroll state detection when unsupported
- Does not use continuous scroll event listeners for scroll state detection
- Styles fallback sentinel elements to have zero dimensions or use absolute positioning
- Hides the floating element by default at the top of the container
- Uses transitionable visibility to handle entry/exit animations and avoid tab order when hidden
