Subgrid: Cross-Wrapper Alignment

This demo shows how grid-template-columns: subgrid allows elements inside separate structural wrappers (the gray boxes) to align their columns perfectly with one another by sharing the parent grid's tracks.

ℹ️ Your browser does NOT support CSS Subgrid. Using a fixed-width fallback.
✅ Your browser supports CSS Subgrid. Columns are dynamically synchronized across wrappers.
