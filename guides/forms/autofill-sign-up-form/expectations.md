# Expectations: `autofill-sign-up-form`

* Input elements are within a `<form>` element.
* The form has a submit button using `<button>` or `<input type="submit">`.
* Every `<input>` in the form is labeled using a `<label>` element.
* Every `<label>` has a `for` attribute matching an input `id`.
* The email input has `type="email"`.
* The email input has `autocomplete="username"`.
* The password input has `type="password"`.
* The password input has `autocomplete="new-password"`.
* The email input has the `required` attribute.
* The password input has the `required` attribute.
* There is exactly one email input.
* There is exactly one password input.
* Name input pattern allows Unicode characters and does not restrict to Latin-only.
