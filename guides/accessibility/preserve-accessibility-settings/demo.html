Preserve User Accessibility with revert

This demo illustrates how the revert keyword restores a property's value to whatever was defined in the User stylesheet (accessibility settings) or the User-Agent (browser default), effectively ignoring the website's custom "Author" styles.

Sample Content

This element is the target. When "Apply Custom Theme" is clicked, it uses author-defined styles. When "Apply revert" is clicked, it uses the revert keyword to ignore those author styles and favor your browser or system accessibility preferences.

Try changing your browser's default font size or color settings to see revert in action.
