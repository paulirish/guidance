Preserve User Accessibility with revert

Restore property values to the User stylesheet (accessibility settings) or User-Agent (browser defaults) while ignoring custom "Author" styles.

Sample Content

When "Apply Low Contrast" is clicked, it uses author-defined styles that might be hard to read. "Apply revert" uses the revert keyword to honor your browser or system preferences.

Tip: Change your browser's default font size or colors to see revert in action.
