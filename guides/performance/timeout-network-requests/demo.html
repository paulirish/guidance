Network Request Timeout

This demo demonstrates how to use AbortSignal.timeout() to automatically cancel a network request that takes too long. The button below triggers a fetch to an endpoint with a 5-second delay, but the timeout is set to 2 seconds.

Notice: Your browser does not support AbortSignal.timeout(). This demo requires a modern browser (Chrome 103+, Firefox 100+, Safari 16+).
