# Expectations

- Standard scrollbar-width property is used in CSS
- Standard scrollbar-color property is used in CSS
- Legacy ::-webkit-scrollbar is wrapped in @supports not (scrollbar-color: auto)
- Legacy ::-webkit-scrollbar has width or height defined for visibility
- Scrollable element has scrollbar-width applied
- Scrollable element has scrollbar-color applied
- The thumb color of each `scrollbar-color` value has a contrast ratio of at least 3:1 against its track color.
